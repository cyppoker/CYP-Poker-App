# CYP Poker App

Player-facing Expo companion for the CYP Tournament Manager.

This is a separate application with no tournament-director or administration
controls. It is also entirely separate from CWG Poker Director.

## Run

```bash
npm install
npx expo start
```

The prototype reads live public data from `https://cyppoker.co.uk`. Player
accounts and online tournament registration are intentionally reserved for a
later phase.
